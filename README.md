# PAIN

## Requirements

- Python 3.14+
- uv (package manager)

Install uv:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Install Dependencies

```sh
uv sync
```

## Run program

```sh
uv run -m pi_server
```

## For Devs

```sh
uv run ruff check .
uv run ruff format .
```
